# Магазин электронных комплектующих

Курсовой проект на Python: моделирование магазина электронных компонентов, инструментов и сопутствующих услуг. Включает консольную демонстрацию, веб-интерфейс, анализ оптимальной закупки и расчёт коэффициента технического уровня (КТУ).

## Возможности

- Модели электронных компонентов: резисторы, конденсаторы, микросхемы, транзисторы и диоды.
- Работа с платами, разъёмами, паяльным и измерительным оборудованием.
- Моделирование услуг, взаимодействия с клиентами и серийного производства.
- Минимизация затрат на закупку при заданной целевой прибыли и ограничениях поставщиков с помощью `scipy.optimize.linprog`.
- Расчёт КТУ и построение радарных и столбчатых диаграмм.
- Веб-интерфейс с каталогом, анализом закупок и импортом записей из JSON или TXT с JSON-содержимым.
- Отдельный Jupyter Notebook для анализа данных и машинного обучения в папке `ML/`.

## Установка

Используйте Python 3.10 или новее. Выполняйте команды из корня проекта.

Создайте виртуальное окружение:

```powershell
python -m venv .venv
```

Активируйте его в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

В Linux или macOS:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
python -m pip install -r requirements.txt
python -m pip install matplotlib
```

`matplotlib` требуется для `main.py` и визуализации, но пока не включён в `requirements.txt`.

## Веб-интерфейс

```bash
python server.py
```

Откройте [http://localhost:5000](http://localhost:5000). Документация API доступна по адресу [http://localhost:5000/docs](http://localhost:5000/docs).

Сервер использует FastAPI и отдаёт файлы из `frontend/`. Интерфейс хранит локальные записи в `localStorage` браузера, а сервер сохраняет импортированные записи в `data.json`. Для загрузки Chart.js с CDN требуется подключение к интернету.

Доступные методы API:

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/records` | Получить записи из `data.json` |
| POST | `/api/upload` | Импортировать файл через поле формы `file` |

Импорт ожидает JSON-объект, где ключи обозначают типы записей, а значения — списки объектов. Формат записей можно посмотреть в `data.json`. Импорт добавляет записи к существующим и назначает им новые `_id`.

## Консольный режим

Запуск демонстрации со встроенными данными:

```bash
python main.py
```

Расчёт закупки по готовому примеру:

```bash
python main.py --file input_example.json
```

Файл параметров закупки содержит:

| Поле | Описание |
| --- | --- |
| `category` | Название категории |
| `selling_price` | Цена продажи единицы товара |
| `target_profit` | Целевая прибыль |
| `suppliers` | Список поставщиков |
| `suppliers[].name` | Название поставщика |
| `suppliers[].cost_per_unit` | Закупочная цена единицы |
| `suppliers[].max_capacity` | Максимальный объём поставки |

`input_example.json` предназначен для консольного анализа закупки; для импорта записей в веб-интерфейсе используется другой формат, описанный выше. Параметр `--file` меняет данные закупки, а демонстрационные объекты остальных разделов остаются встроенными.

Сохранение диаграмм КТУ в PNG:

```bash
python main.py --chart radar --save-dir out
python main.py --chart bar --category tools --save-dir out
```

Доступные категории: `all`, `electronic_components`, `components`, `tools`, `services`, `additional_services`, `customer_relations`.

Для визуализации используется неинтерактивный backend `Agg`, поэтому указывайте `--save-dir`, чтобы получить изображения. Если показателей недостаточно для радарной диаграммы или их число у объектов различается, строится столбчатая диаграмма.

Справка по аргументам:

```bash
python main.py --help
```

## Структура проекта

```text
University_Python_Course_Work/
├── main.py                  # Консольная демонстрация и аргументы запуска
├── server.py                # FastAPI: веб-интерфейс и импорт данных
├── requirements.txt         # Основные зависимости
├── input_example.json       # Пример входных данных для анализа закупки
├── data.json                # Серверные записи каталога
├── models/                  # Модели компонентов, услуг и клиентов
├── classes/                 # Объединение моделей по категориям
├── analysis/                # Оптимальная закупка и расчёт КТУ
├── visualization/           # Построение диаграмм средствами Matplotlib
├── frontend/                # HTML, CSS и JavaScript веб-интерфейса
└── ML/                      # Notebook, наборы данных и результаты ML
```

Для работы с `ML/machine_learning.ipynb` дополнительно понадобятся Jupyter и библиотеки, импортируемые в ноутбуке, в том числе `pandas`, `seaborn` и `scikit-learn`. Зависимости ноутбука не входят в основной `requirements.txt`.
